# 学习进度记录

> 本文件是每日学习进度的唯一载体，配合 [`docs/30-day-plan.md`](30-day-plan.md)（v3.0）使用。
> 计划文件不承载进度状态；每日学习结束后在此标记。

## 使用说明

- 每日学习结束后，在下方表格中标记当日状态：
  - ✅ 完成：当日主题全部达到验收标准
  - ⚠️ 部分完成：有未消化项，记入"备注"并在次日/周复盘优先补齐
  - ❌ 未完成：记入"备注"说明原因，触发调速（只降速，不跳主题）
- 掌握度按三级标记：`已掌握` / `进行中` / `未掌握`
- 每周日（D7/D14/D21/D28）复盘时，逐主题更新掌握度，并据此调整下周计划
